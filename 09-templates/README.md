# Templates

These are copy-and-tailor templates for a new product or material feature. They are deliberately concise: complete the relevant fields, link evidence instead of duplicating it, and mark an unknown as a decision needed rather than inventing an answer.

Do not copy customer data, secrets, access tokens or production identifiers into any template.

## Phase sub-steps

1. Product requirement document and discovery decision template — complete
2. User story, workflow and acceptance-criteria templates — complete
3. Architecture, ADR, data model and API contract templates — complete
4. Security, privacy, access and threat-model templates — complete
5. Test strategy, test-case, UAT and quality-evidence templates — complete
6. Release, rollout, rollback and operational-readiness templates — complete
7. Incident, post-incident and project handover templates — complete
8. CI/CD GitHub Actions pipeline template — complete ([`ci-cd-github-actions-template.md`](ci-cd-github-actions-template.md))
