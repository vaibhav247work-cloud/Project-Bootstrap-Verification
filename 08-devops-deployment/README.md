# DevOps and Deployment

This area defines how the product is built, configured, deployed, observed, recovered and operated safely. It complements the CI/release testing rules in `07-testing/`.

## Phase sub-steps

1. Environment, configuration, feature-flag and secrets management — complete
2. Container/runtime, health checks and application process standard — complete
3. CI/CD artifact, registry, deployment and rollout standard — complete
4. Observability, alerting, SLO and operational dashboard standard — complete
5. Database migrations, backups, retention and disaster recovery operations — complete
6. Infrastructure/network/security hardening and access management — complete
7. Incident response, runbooks, on-call and post-incident improvement — complete

`redis-standard.md` remains the mandatory Redis-specific companion to these cross-platform operations rules.
