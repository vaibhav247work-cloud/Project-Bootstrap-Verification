# Cross-Stack Testing

This area defines quality rules that apply across React, Spring Boot, MySQL, Redis, deployment and real user journeys. It complements framework-level tests; it does not duplicate them.

## Phase sub-steps

1. Quality strategy, test layers, ownership and risk coverage — complete
2. Spring Boot, MySQL, Redis and external-integration testing — complete
3. API contract, end-to-end and cross-tenant testing — complete
4. Security, privacy and resilience verification — complete
5. Performance, load, scalability and recovery testing — complete
6. Test environments, test data and user acceptance testing — complete
7. Cross-stack CI, release evidence and defect management — complete

No production release skips a relevant security, tenant-isolation, data-integrity or critical-workflow test merely because unit tests pass.
