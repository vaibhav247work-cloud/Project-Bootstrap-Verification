# Project Start

Read the universal standards before any new project begins. Then use Discovery, Architecture, Security, and the technology-specific playbooks to make project decisions.

The required initial project artifacts are:

- `../01-discovery/project-brief.md`
- `../06-security/security-and-access-matrix.md`
- An ADR in `../02-architecture/adr-and-governance/` for any meaningful non-default decision
