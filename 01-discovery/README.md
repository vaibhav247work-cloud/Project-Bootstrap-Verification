# Discovery

Define the client problem, users, workflows, scope, success metrics, acceptance criteria, and non-functional requirements before architecture or coding decisions.

## How to use

1. Run a discovery session using `discovery-session-guide.md`. Complete every MUST item or assign a named owner and due date.
2. Fill in `project-brief.md` with the outputs.
3. Complete `../06-security/security-and-access-matrix.md` Steps 1–5 for access and data classification decisions.
4. Approve the PRD (`../09-templates/product-requirements-document-template.md`) before architecture or implementation starts.

Nothing in `02-architecture/` or later sections should be decided before this section is complete.
