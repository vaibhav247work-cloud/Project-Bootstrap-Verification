# React + TypeScript Standards

This folder contains the default React web frontend standards. It is deliberately separate from the cross-frontend area so that future React Native or another framework can have its own implementation rules without mixing architecture.

## Standards

- `testing-ci-and-release.md` - test layers, CI quality gate and release checklist

- `react-architecture.md` — feature-first application structure and boundaries
- `frontend-code-quality.md` — TypeScript, components, styling and file boundaries
- `routing-auth-and-permissions.md` — routing, session lifecycle, tenant and permission-aware UX
- `api-state-and-cache.md` — typed API client, server state, local state, cache and retry policy
- `forms-validation-and-feedback.md` — forms, validation, user feedback, drafts and file-upload UX
- `responsive-accessible-modern-ui.md` — responsive/reactive/dynamic UI, modern visual system, pointer, motion, 3D, accessibility and i18n direction
- `browser-security-and-error-handling.md` — XSS/CSP/storage/privacy, error boundaries, safe telemetry and dependency boundaries
- `performance-pwa-and-native-decision.md` — performance budgets, bundle/media rules, PWA/offline safety and native-mobile decision gate
